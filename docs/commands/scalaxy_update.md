## scalaxy update

Update the CLI to the latest version

### Synopsis

Download and install the latest version of the Scalaxy CLI from GitHub releases.

```
scalaxy update [flags]
```

### Options

```
      --check-only       Only check for updates without installing
      --force            Force update even if already on the latest version
  -h, --help             help for update
      --version string   Specific version to install (e.g., v1.2.3)
```
