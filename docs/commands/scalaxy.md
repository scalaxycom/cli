## scalaxy

Scalaxy Metal CLI — manage bare-metal servers

### Synopsis

Command-line interface for the Scalaxy Metal bare-metal cloud platform.

### Options

```
      --api-key string   API key for authentication
      --debug            Enable debug mode
  -h, --help             help for scalaxy
      --no-color         Disable colored output
      --org string       Organization context override
  -o, --output string    Output format: table, json, yaml (default "table")
      --project string   Project context override
  -q, --quiet            Suppress non-essential output
  -y, --yes              Skip confirmation prompts
```
